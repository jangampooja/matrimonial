# ShaadiMatch – Matrimonial Website

A responsive, front-end-only matrimonial matchmaking demo built with HTML5, CSS3 and vanilla JavaScript.

## Run locally
1. Download and extract `shaadimatch_project.zip`.
2. Open the folder in Visual Studio Code.
3. Open `index.html` in a browser, or install the **Live Server** extension and select **Open with Live Server**.
4. No npm install or database is required.

## Features
- Responsive home page, navigation, hero section and quick search
- Profile registration in three steps (personal, family, education/career)
- Profile cards, profile detail view and advanced filters
- Simulated registration/login
- Send interest and shortlist profiles
- Local demo chat interface
- Success stories, About and Contact sections
- Dark mode
- Browser `localStorage` persistence for profiles, interests, shortlist, user session and messages

## Data and limitations
This is a frontend-only demonstration. Sample members and testimonials are fictional demo content. Login, chat, contact submission and interests are simulated in the browser; there is no real authentication, server, database, email delivery, identity verification, secure messaging, or real-time notifications. Data is stored only in the current browser's local storage and can be cleared by clearing site data. Do not use real passwords or sensitive personal information.

## Files
- `index.html` – page structure and modal forms
- `style.css` – layout, styling, responsive rules and dark mode
- `script.js` – sample data, filtering, registration, interests, shortlist and chat logic

## Deployment
Push these three files and this README to a public GitHub repository. For GitHub Pages, open **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save. Wait for the published URL to appear.
